## Первый запуск и размер текста

Проверено 02.11.2026 по официальным [Setup guide](https://docs.granola.ai/help-center/getting-started/setting-up-granola-for-the-first-time)
и [Signing in and connecting your calendar](https://docs.granola.ai/help-center/signing-in-and-connecting-your-calendar).
Granola: вход Google/Microsoft связывает календарь, затем macOS запрашивает
Microphone и System Audio Recording. После этого показывается двухминутная
демо-встреча и главный экран. Демо показывается один раз, его можно открыть
повторно. Выбора или установки ASR-моделей в этом пути нет. Это описание
официального сценария, а не обещание точного числа экранов текущего бинарника.

В notetaker три коротких экрана: звук, имя, необязательные подключения
календаря и AI. У звука отдельный результат по каждому каналу и подсказка
по разрешениям; тишина не считается успешной проверкой. Имя обозначает голос
владельца. Подключения свёрнуты; без AI доступны запись, текст и локальный поиск.
Первый показ отмечается в конфигурации, повторный доступ: «Общие → Быстрый старт».
Старые конфигурации без нового маркера считаются уже настроенными.

Модели обслуживает приложение: сначала GigaAM для ru или многоязычный Parakeet
для остальных системных языков, детектор тишины загружается вместе с ASR. Затем segmentation + speaker embedding,
затем multilingual-e5-small и его worker. Если язык ОС недоступен, используется
русский язык интерфейса. «Авто» с определением языка остаётся в «Для опытных»
и загружает обе ASR-модели и language identifier автоматически.
Запись доступна после готовности выбранного ASR. Загрузка остальных моделей
может продолжаться во время записи; следующие загрузки ждут её завершения.
Поиск по словам работает сразу, по смыслу включается после фоновой загрузки
и индексации. Отдельный выбор модели для поиска не нужен: поиск должен работать.
Ошибки показываются в одной строке, повтор автоматически через минуту или
по ссылке «Повторить». Раз в минуту проверяется наличие файлов.

В «Хранилище» два выбора папки и занятое место. По умолчанию модели находятся
в локальных данных приложения; при смене папки недостающие файлы загружаются
повторно, старые не удаляются. Срок хранения аудио и диагностика свёрнуты
в «Для опытных». Путь передаётся всем дочерним ASR/embed-процессам
без изменения окружения работающего приложения.

Размеры в логических точках: основной текст 16, кнопки 15, подписи 13,
подзаголовки 18/21, заголовки 26/32. Это наша адаптация читаемого интерфейса,
не измеренные размеры Granola. Именованные размеры заданы в `theme.rs`.
«Общие → Масштаб интерфейса» и Ctrl+= / Ctrl+- / Ctrl+0 сохраняют масштаб.
Превью реального egui: `python3 scripts/render-onboarding.py`, результаты
в `target/onboarding-previews`, галерея `index.html`: 84 PNG, светлая/тёмная
темы, 1280×800 и 960×640, также 150% в маленьком окне. Подключения показаны
и в раскрытом виде. Это Linux-рендер с fixture-данными, без аудио, загрузок
моделей и пользовательских секретов; нативные разрешения требуют проверки
на Windows/macOS. В строке загрузки считаются три группы, а не отдельные файлы.

## Что переносим

- Боковая колонка: поиск, встречи, чат, папки. Главная: ближайший календарь,
  затем история заметок. Встреча открывается как документ, а не набор панелей.
- Большой заголовок, тихие дата, участники и папка. Личные заметки тёмные,
  дополнения AI серые. В оригинале личные строки выделены внутри конспекта;
  источники можно проверить через транскрипт. Редактирование и шаблоны доступны
  по требованию, не занимают постоянную панель.
- Внизу строка Ask anything и доступ к транскрипту. Во время записи видны
  зелёная волна, время и остановка. Индикатор поверх звонка минимален.
- Папки задают контекст чата. Чат работает по одной встрече и по библиотеке.
  Templates задают структуру конспекта; Recipes являются сохранёнными запросами.
  Новый отдельный механизм Recipes сейчас не нужен: есть шаблоны и чат.
- Светлые тёплые нейтральные поверхности, обычная типографика, свободные поля,
  тонкие разделители. Единственный акцент зелёный для записи. Это адаптация
  утверждённого макета, не обещание пиксельного совпадения всех версий Granola.
- В актуальном changelog есть Briefs, People, team folders, агентный Chat и
  Recipes. Не копируем все функции: продуктовое ограничение важнее полноты.

## Соответствие

| Granola | notetaker | Решение |
| --- | --- | --- |
| Coming up | ICS-календарь | Оставить простые строки с записью |
| Your notes | История по дням | Оставить, убрать карточки и таймлайн |
| Note document | notes.md + enhanced.md | Один документ, тёмный оригинал и серые дополнения |
| Ask anything | Чат встречи / библиотеки | Нижняя строка и экран чата |
| Transcript | Журнал реплик | Из нижней строки, без постоянных вкладок |
| Recording | Захват + индикатор | Зелёная волна, таймер, Стоп |
| Folders | Виртуальные папки | Оставить, нейтральные квадраты |
| Templates / Recipes | Шаблоны + чат | Оставить шаблоны, не добавлять новый редактор Recipes |
| People / recurring context | Люди и серии | Оставить в «Ещё» |
| Follow-up / actions | Задачи и трекеры | Оставить задачи в «Ещё», сообщения через чат |
| Cross-meeting summaries | Дайджест | Оставить в «Ещё» |
| Нет в выбранном сценарии | Живой конспект, обзор пропущенного, закладки и метки | Убрать UI и связанные настройки/хоткеи |
| Нет в макете | Рейка иконок, цветные папки, точки спикеров, фильтры-чипы, теги | Убрать из основного UI |
| Вне текущего набора | Импорт аудио/видео, отдельные панели брифа и сообщения | Убрать UI; сообщения задаются в чате, backend остаётся |
| Настройки | Быстрый старт, диагностика, обновления | Единые строки и разделители, без рамок-карточек |

## Данные и ограничения

`notes.md` уже хранит текст пользователя, `enhanced.md` результат AI. Не угадываем
авторство перефразированных строк. Совпадающие личные строки показываем тёмными,
остальные серыми; отсутствующие в конспекте личные заметки сохраняем в том же
документе перед дополнениями. Редакторы сохраняют исходные файлы отдельно.
Схема и миграция не требуются. Старые поля конфигурации остаются читаемыми,
но удалённые горячие клавиши больше не регистрируются.

## Число собеседников в транскрипте

Тихая строка «Собеседников: N» считает голоса системной дорожки отдельно от mic.
Меню: «Авто» и 1..8. Перед запуском показана одна строка о сбросе имён и связей
с голосами, затем «Применить» или «Отмена». Пересчёт идёт в фоне через общий
с CLI `rediarize` pipeline: точная резервная копия транскрипта, текст, правки,
тайминги и mic сохраняются. Прогресс: «Пересчитываю спикеров…»; ошибка через
существующее уведомление. Во время записи и без `audio/system.opus` действие
недоступно, причина видна в подсказке. Текущие операции сохранения тоже блокируют
запуск. Число голосов не является обещанием точной атрибуции, см. проверку диаризации.

Таблица статистики и таймлайн убраны. Переименование остаётся в меню имени у
реплики, объединение в тихом меню над текстом. Действия назначения выбранных
реплик появляются только при выборе.

Превью на текущем checkout: `bash target/render-transcript.sh` использует
существующий harness и обновляет contact sheets. Файлы остаются под `target/`:
`granola-previews/transcript-{light,dark}.png`, варианты `transcript-menu`,
`transcript-warning`, `transcript-progress`, `contact-{light,dark}.png`.
Это настоящий egui renderer на fixture-данных, без записи и worker-операций.
