# Интерфейс по образцу Granola

Проверено 02.11.2026. Основа: [сайт](https://www.granola.ai/),
[Granola 101](https://docs.granola.ai/help-center/getting-started/granola-101),
[конспект и скриншоты](https://docs.granola.ai/help-center/taking-notes/ai-enhanced-notes),
[транскрипция](https://docs.granola.ai/help-center/taking-notes/transcription),
[Recipes](https://docs.granola.ai/help-center/getting-more-from-your-notes/recipes),
[обновления](https://www.granola.ai/updates).
Свежий [публичный обзор от 21 октября](https://learn.ynteractive.com/content/blog/granola-call-notes-faq)
подтверждает нижнюю строку вопросов и зелёную волну, но сам автор предупреждает:
это учебная реконструкция, не снимок работающего приложения. Поэтому внешний вид
берём с официальных снимков и утверждённого `target/granola-mockup.html`.

## Что переносим

- Боковая колонка: поиск, встречи, чат, папки. Главная: ближайший календарь,
  затем история заметок. Встреча открывается как документ, а не набор панелей.
- Большой заголовок, тихие дата, участники и папка. Личные заметки тёмные,
  дополнения AI серые. В оригинале личные строки выделены внутри конспекта;
  источники можно проверить через транскрипт. Редактирование и шаблоны доступны
  по требованию, не занимают постоянную панель.
- Внизу строка Ask anything и доступ к транскрипту. Во время записи видны
  зелёная волна, время и остановка. Индикатор поверх звонка минимален.
- Папки задают контекст чата. Чат работает по одной встрече и по библиотеке.
  Templates задают структуру конспекта; Recipes являются сохранёнными запросами.
  Новый отдельный механизм Recipes сейчас не нужен: есть шаблоны и чат.
- Светлые тёплые нейтральные поверхности, обычная типографика, свободные поля,
  тонкие разделители. Единственный акцент зелёный для записи. Это адаптация
  утверждённого макета, не обещание пиксельного совпадения всех версий Granola.
- В актуальном changelog есть Briefs, People, team folders, агентный Chat и
  Recipes. Не копируем все функции: продуктовое ограничение важнее полноты.

## Соответствие

| Granola | notetaker | Решение |
| --- | --- | --- |
| Coming up | ICS-календарь | Оставить простые строки с записью |
| Your notes | История по дням | Оставить, убрать карточки и таймлайн |
| Note document | notes.md + enhanced.md | Один документ, тёмный оригинал и серые дополнения |
| Ask anything | Чат встречи / библиотеки | Нижняя строка и экран чата |
| Transcript | Журнал реплик | Из нижней строки, без постоянных вкладок |
| Recording | Захват + индикатор | Зелёная волна, таймер, Стоп |
| Folders | Виртуальные папки | Оставить, нейтральные квадраты |
| Templates / Recipes | Шаблоны + чат | Оставить шаблоны, не добавлять новый редактор Recipes |
| People / recurring context | Люди и серии | Оставить в «Ещё» |
| Follow-up / actions | Задачи и трекеры | Оставить задачи в «Ещё», сообщения через чат |
| Cross-meeting summaries | Дайджест | Оставить в «Ещё» |
| Нет в выбранном сценарии | Живой конспект, обзор пропущенного, закладки и метки | Убрать UI и связанные настройки/хоткеи |
| Нет в макете | Рейка иконок, цветные папки, точки спикеров, фильтры-чипы, теги | Убрать из основного UI |
| Настройки | Быстрый старт, диагностика, обновления | Единые строки и разделители, без рамок-карточек |

## Данные и ограничения

`notes.md` уже хранит текст пользователя, `enhanced.md` результат AI. Не угадываем
авторство перефразированных строк. Совпадающие личные строки показываем тёмными,
остальные серыми; отсутствующие в конспекте личные заметки сохраняем в том же
документе перед дополнениями. Редакторы сохраняют исходные файлы отдельно.
Схема и миграция не требуются. Старые поля конфигурации остаются читаемыми,
но удалённые горячие клавиши больше не регистрируются.
