# Чтение встреч через MCP

`notetaker mcp` запускает локальный сервер JSON-RPC 2.0 по stdio. Сокетов и
HTTP-сервера нет; stdout содержит только сообщения протокола, по одному JSON на
строку. Поддержаны initialize, ping, tools/list и tools/call. Собственный
синхронный транспорт использует уже имеющиеся serde_json и std::io, без rmcp и
дополнительного async runtime. Протоколы: 2024-11-05, 2025-03-26, 2025-06-18.
[Спецификация stdio](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports).

Сервер читает библиотеку из `app.toml`, либо из `--library <полный-путь>`:

```text
notetaker.exe mcp --library C:\Users\User\Documents\notetaker
```

Инструменты:

- `search_meetings(query, limit=10)` - безопасный поиск по словам, BM25,
  id/название/фрагмент. limit до 100.
- `get_meeting(id)` или `get_meeting(path)` - meta, заметки, конспект,
  транскрипт с подтверждёнными именами. Путь только внутри библиотеки.
- `list_recent(n=10)` - последние доступные встречи, до 100.

Встречи не изменяются. Перед поиском обновляется только пересоздаваемый
SQLite-индекс в `.notetaker`. Голосовые отпечатки, аудио и URL подписок
инструментам не доступны. Контент встречи может содержать персональные данные;
подключайте сервер только к доверенным клиентам.

Настройка «MCP: не отдавать Local-встречи» включена по умолчанию
(`mcp_exclude_local = true`). Она применяется ко всем трём инструментам,
включая прямой id/path, до выдачи данных и до ограничения числа результатов.
Режим берётся из текущего `meta.yaml`, а не из индекса. После изменения настройки
перезапустите MCP-клиент. Нельзя запросить выключение фильтра аргументом инструмента.

## Claude Code

```powershell
claude mcp add notetaker -- 'C:\Apps\notetaker\notetaker.exe' mcp
```

Либо добавьте `--library` после `mcp`. См.
[документацию Claude Code](https://code.claude.com/docs/en/mcp).

## Codex

В `~/.codex/config.toml` (Windows: `%USERPROFILE%\.codex\config.toml`):

```toml
[mcp_servers.notetaker]
command = 'C:\Apps\notetaker\notetaker.exe'
args = ['mcp']
```

С отдельной библиотекой:
`args = ['mcp', '--library', 'C:\Users\User\Documents\notetaker']`.
Синтаксис соответствует [официальной документации Codex MCP](https://developers.openai.com/codex/mcp/).

## Встроенный чат

«Спросить» ищет до шести встреч через FTS5/BM25, убирая частые русские и
английские слова. «Спросить про эту встречу» использует её заметки, конспект и
транскрипт. Длинный контекст сжимается map/reduce с ограничением контекста
выбранной модели. Ответ поступает потоково; кнопки [N] с названием и датой
открывают встречи-источники. Это ссылки на встречи, не точные таймкоды реплик.

История хранится только в памяти (до 20 ответов, в запрос идут последние шесть).
При смене области диалог очищается. Если любой источник или история содержат
Local-данные, запрос полностью идёт локальному провайдеру; без корректного
локального провайдера чат отказывает до создания облачного клиента.

Настройки «Модели по сценариям» отдельно задают провайдер и модель для конспекта
и чата. Пустые поля наследуют прежние Local/Hybrid defaults. Для Local облачный
сценарий заменяется локальным default и его моделью; явный CLI `--provider`
для конспекта по-прежнему проверяется на совместимость с режимом встречи.
Пример дополнительной секции LLM `config.toml`:

```toml
[scenarios.summary]
provider = "ollama"
model = "qwen3:8b"

[scenarios.chat]
provider = "flant"
model = "claude-sonnet-4-6"
```

Указанные provider id должны существовать в `[[providers]]`.
Отмена CLI останавливает дочерний процесс; HTTP-запрос завершается по ответу
или существующему таймауту провайдера, после чего отменённый ответ отбрасывается.
