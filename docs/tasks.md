# Задачи

«Задачи» в боковой панели собирают флажки из `enhanced.md` всех встреч:

```markdown
- [ ] Обновить кластер - Иван - до пт
- [x] Проверить резервную копию - Анна - 30.10.2026
```

Работают вложенные списки, нумерация, `*`/`+`, разделители ` | ` и `; `,
поля `Ответственный:` / `Срок:`. Блоки кода не индексируются. Неизвестный
ответственный или срок остаётся пустым. «Завтра», «сегодня», «послезавтра»,
«до пт» считаются от даты встречи (UTC); `30.10` означает ближайшее такое
число, включая следующий год. Неоднозначные сроки остаются текстом.

Фильтры: открытые/все, «Мои», ответственный. Группировка по владельцу или
встрече. Просроченные задачи выделены красным. Клик открывает редактор конспекта
на исходной строке. Флажок атомарно меняет только эту строку; при внешней
правке revision защищает файл, локальная версия сохраняется в conflict-файл.
Обновление перечитывает библиотеку. SQLite содержит только пересобираемый
индекс; новая схема автоматически сбрасывает старый индекс.

В настройках «Как вас зовут» задайте имя и алиасы через запятую, точку с
запятой или новую строку. «Мои» сопоставляет полное имя/алиас без учёта регистра,
Ё/Е, лишних пробелов и начального `@`. Имя подставляется собственному спикеру
при открытии/завершении встречи и перед конспектом, если имени ещё нет;
подтверждённые имена сохраняются.

```sh
notetaker tasks --open
notetaker tasks --mine --open --library /path/to/library
```

Read-only MCP `list_tasks(status, owner)`: `status` = `open`, `completed`/`done`
или `all` (по умолчанию). Возвращает встречу, путь, строку, текст, владельца,
исходный и разобранный срок, состояние флажка. Настройка исключения Local
проверяется по исходной metadata, даже при старом индексе.

## Бриф и сообщения после встречи

Бриф перед встречей и черновики сообщений команде или клиенту удалены из
интерфейса. Их backend и шаблоны сохранены для дальнейшей работы; кнопок
создания и редактора этих документов в приложении сейчас нет.

## Экспорт и папки

Конспект сохраняется автоматически в `enhanced.md`. «Копировать» берёт текст,
«Показать в папке» выделяет файл в Проводнике Windows (на других ОС открывает
папку). Экспорт находится только в меню «Экспорт»: `<slug>.summary.md`,
`<slug>.transcript.md|srt|vtt|csv|json`. Повторная команда атомарно обновляет
тот же файл; toast показывает имя и кнопку открытия папки. Windows-префиксы
`\\?\` и `\\?\UNC\` скрываются в отображаемых путях.

Имена новых папок встреч используют локальное время компьютера. Старые папки
не переименовываются; `started_at` в metadata сохраняет прежнюю семантику UTC.

## Папки и трекеры (0.13.0)

Выбранная папка ограничивает список задач, `--folder` задаёт фильтр в CLI,
MCP `list_tasks` принимает `folder`. Ссылки `[Трекер](https://...)` рядом со
строками сохраняются при переключении флажка и входят в индекс.
«Отправить в трекер» открывает просмотр JSON; для Local нужно отдельное
подтверждение. Подробности: [трекеры](trackers.md), [папки](organization.md).
