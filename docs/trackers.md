# Задачи в трекер (0.13.0)

В настройках папки включите «Трекер по умолчанию», выберите сервис и URL.
Конфигурация синхронизируется через `folders.json`, секреты туда не попадают.
Поле «Имя ключа» - идентификатор, сам токен вводится в скрытом поле и
сохраняется в Windows Credential Manager. На другом компьютере каждый
участник вводит свой ключ под тем же именем. На других ОС встроенное
хранилище пока недоступно; webhook без подписи работает без ключа.

В «Задачи» или «Задачи в трекер» над конспектом нажмите «Отправить в трекер».
Для всей встречи есть «Отправить все новые задачи встречи». Завершённые и уже
отправленные задачи пропускаются. Сначала приложение показывает адрес и
точный JSON без токенов. Только «Отправить» выполняет HTTP-запрос.

Для Local нужен отдельный флажок подтверждения: задача и до 2000 символов
конспекта покинут компьютер. Режим проверяется ещё раз непосредственно перед
отправкой. При смене режима после просмотра отправка блокируется.

## Провайдеры

- **Webhook**: полный URL обработчика. POST JSON: `task`, `owner`, `due`,
  `due_text`, `meeting` (название, дата, `notetaker://meeting/<uuid>`, фрагмент
  конспекта, email ответственного) и `idempotency_key`. Ответ - JSON
  `{"url":"https://tracker.example/issue/123"}`. Необязательный секрет из
  Credential Manager включает HMAC-SHA256 по точным байтам JSON.
  Заголовок по умолчанию `X-Notetaker-Signature`, значение `sha256=<hex>`.
- **Kaiten**: URL инсталляции без `/api`, токен, числовые ID пространства,
  доски, колонки и дорожки. Имя карточки - текст задачи; описание содержит
  контекст, встречу и выдержку конспекта. Email участника сопоставляется с
  ID ответственного через явный JSON-словарь, например
  `{"anna@example.org":123}`. Если соответствия нет, владелец остаётся в
  описании. Нажмите «Загрузить / обновить структуру Kaiten», выберите пространство,
  обновите список, выберите доску, обновите колонки и дорожки. ID также
  можно задать вручную из URL и API своей инсталляции.
- **Jira**: URL инсталляции, ключ проекта, название типа задачи. Email +
  API token используют Basic auth; пустой email + PAT используют Bearer.
  Флажок Cloud включает REST v3 с ADF-описанием; иначе REST v2 с текстом.
  Срок передаётся отдельным `duedate`; ответственный остаётся в описании.
- **YouTrack**: URL инсталляции, permanent token и внутренний ID проекта
  (например `0-1`, не короткое имя). POST `/api/issues`; ответ `idReadable`
  превращается в ссылку на задачу. Владелец и срок сохраняются в описании.

API: [Kaiten](https://developers.kaiten.ru/cards/create-new-card),
[Jira Cloud](https://developer.atlassian.com/cloud/jira/platform/rest/v3/api-group-issues/),
[Jira Server](https://developer.atlassian.com/server/jira/platform/jira-rest-api-examples/),
[YouTrack](https://www.jetbrains.com/help/youtrack/devportal/api-howto-create-issue.html).

## Повторная отправка и сбои

После успеха рядом с исходной строкой `enhanced.md` появляется
`[Трекер](https://...)`; ссылка также входит в пересобираемый индекс задач.
Скрытая квитанция `.tracker-<hash>.json` в каталоге встречи записывается до
изменения конспекта и синхронизируется вместе с ним. Квитанция с URL позволяет
восстановить ссылку без повторного POST при конфликте конспекта.

До запроса сохраняется квитанция `{"url":null}`. Таймаут, аварийное завершение
или нераспознанный ответ оставляют её, блокируя автоматический повтор: трекер
мог уже создать карточку. Проверьте трекер. Если карточка есть, добавьте её
ссылку в исходную строку вручную; если точно нет - удалите соответствующую
квитанцию и повторите просмотр. HTTP-ошибки также требуют этой проверки.

Синхронизируемая папка не даёт распределённой блокировки: до получения чужой
квитанции два компьютера могут отправить одну задачу одновременно. Договоритесь
об одном отправляющем. Заголовок `Idempotency-Key` помогает webhook-получателю
устранить дубли; остальные API не гарантируют его поддержку. Переименование
или перенос строки задачи без ссылки не является безопасным повтором.
