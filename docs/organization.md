# Папки и теги (0.13.0)

Папка - виртуальная группа встреч, например `client/project`. В `meta.yaml`
добавляются необязательные `folder` и `tags`; каталоги встреч остаются на месте.
Старые библиотеки открываются без миграции.

В боковой панели доступны дерево с количеством встреч, «Без папки» и фильтры
тегов. Выбор родителя включает подпапки. Папка также ограничивает задачи,
людей, серии и дайджест. [Поиск в списке встреч](search.md) учитывает
выбранную папку и тег внутри keyword-, semantic- и hybrid-поиска, до лимита результатов. Чат по библиотеке
ограничивает источники выбранной папкой. Local-данные остаются локальными.

Перетащите встречу на папку. Для нескольких встреч используйте Ctrl+клик
(Cmd+клик на macOS), затем перетащите выделение либо откройте меню папки и
выберите «Переместить выбранные сюда». В самой встрече можно сменить папку и
отредактировать теги через запятую.

Через меню папки или «Папки / общая библиотека» задаются:

- Имя; `/` создаёт уровень дерева.
- Шаблон конспекта, дополнения словаря, режим и число собеседников.
- Правила календаря: подстрока названия и/или точный домен email участника.
  Внутри строки условия объединяются И, строки объединяются ИЛИ.
- Трекер для новых задач: [настройка](trackers.md).

При создании встречи приоритет: правило календаря, последняя встреча серии
с тем же UID календаря, выбранная папка. При нескольких подходящих правилах
первой выбирается папка по алфавиту. Совпадения по похожим названиям без
календарного UID не угадываются до появления подтверждённых спикеров.
Режим, явно изменённый в диалоге записи/импорта, важнее значения папки.
Local-бриф всегда оставляет новую встречу Local.

Настройки лежат в `<library>/.notetaker/folders.json`. Переименование меняет
папку и подпапки в metadata; удаление снимает назначение, сохраняя встречи.
Совместные правки защищены revision: при конфликте локальная версия остаётся
в отдельном `.conflict-*` файле, внешняя версия не перезаписывается.

```sh
notetaker record --library /path/to/library --title 'Созвон' --folder client
notetaker import call.mp4 --folder client
notetaker search 'бюджет' --mode hybrid --folder client
notetaker tasks --open --folder client
notetaker people --folder client
notetaker person anna@example.org --folder client
notetaker digest --week --folder client
```

Пустая строка `--folder ''` выбирает встречи без папки в командах просмотра.
MCP `list_tasks`, `list_people`, `get_person`, `get_series`, `get_digest`,
`search_meetings`, `list_recent`, `get_meeting`, `get_speaker_timeline` принимают необязательный
`folder` с теми же правилами. Политика исключения Local сохраняется.

Для папки на Яндекс Диске включите [общую библиотеку](sharing.md).
Переключатель общей библиотеки и скачивание [модели поиска](search.md) доступны
как независимые необязательные шаги в быстром старте и настройках.
Индекс, фрагменты и векторы общей библиотеки строятся на каждом компьютере
в локальном каталоге, а папки, теги и настройки папок синхронизируются.
